# Tu wrzucasz pliki niespodzianek 🎁

Nazwy plików muszą się zgadzać z tym, co jest wpisane w `../tresci.js`
(np. `02.jpg`, `03.mp3`, `04.mp4`).

- zdjęcia: `.jpg`, `.png`, `.webp`
- głosówki: `.mp3` lub `.m4a` (nagranie z dyktafonu w telefonie działa)
- filmiki: `.mp4` (najlepiej poniżej ~50 MB, żeby szybko się ładowały)
